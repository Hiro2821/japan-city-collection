# カラーグレーディング（映画的な色と光）— 設定・比較・統計（スクロール版のみ）

実装: `src/scroll/grade.js`（新規）、`src/scroll/renderer.js`（renderAt で適用）、`src/scroll/app.js`・`debug.js`。共有の src/renderer.js・src/lib・src/scenes は無変更。

## 現行設定の確認（変更前）
- トーンマッピングは既に ACES Filmic（OutputPass、sRGB 出力）。露出トラックは全編 1.0 固定。
- グレード段（post.js）には既に S 字コントラスト、スプリットトーン、ビネット 0.30、グレイン 0.022、色収差が入っている。
→ 「ACES を新規適用」ではなく、ACES は維持し、露出・色温度・ビネットをスクロール側で調整した。

## 採用した設定
| 項目 | 変更前 | 採用 |
|---|---|---|
| トーンマッピング | ACES Filmic | ACES Filmic（維持） |
| 露出 | ×1.0 固定 | t に応じて 昼(t=0) ×1.15 → 夕(t=7) ×0.90（t/7 の 0.25〜1.0 で smoothstep） |
| ハイライト色 | (1.03,1.0,0.96) | 夕景へ (1.075,1.0,0.905) |
| 影の色 | (0,0.05,0.10) ティール寄り | 夕景へ (0.035,0.03,0.10) 赤みの青紫 |
| 彩度 | 1.04 | 夕景へ 1.075 |
| ビネット | 0.30 | 0.20 |
| ディザ | なし（グレインあり） | 追加なし（下記） |
URL: `?grade=0` で変更前に完全一致、`?grade=1` 既定、倍率で変更量を増減。`?gradeExpDay= ?gradeExpDusk= ?vig=` で個別調整。`?debug=1` にトーンマップ種別・露出・夕景度・ビネットを表示。

## 候補比較
- 露出: 昼/夕 = 1.08/0.95 と 1.16/0.90 を撮影（haze 同様、画像 grade_cand_ex_*.jpg、左から 変更前｜1.08/0.95｜1.16/0.90）。後者は昼が明るく夕が沈む差が明瞭で、白飛ばし・黒潰れは増えない（下表）。→ 1.15/0.90 を採用。
- 色温度: grade_cand_warm_*.jpg（左 変更前、右 採用）。p=0.75〜1.0 で建物の橙とピンクの空が喧嘩せず、影の青紫が空のピンクに寄って奥行きが増した。
- バンディング: 空領域（上部 12%）で、横方向 200 px の平均を取ったときの階調が、全 18 条件で整数からの偏差 0.25（＝一様に分数値）。既存グレイン（±約 1.4〜2.8 段）が既にディザとして働いており、縞は検出されなかったので何も追加していない。
- ビネット: 0.30（現行）/ 0.20（中）/ 0.10（弱）を撮影（grade_cand_vig_*.jpg）。中央（画面中心 30%×30%）の輝度は 3 案とも同じ（差 0.3 以下）。隅は現行 0.30 で横画面だと中心の約半分（p=0.5 横: 中心 173.8 / 隅 79.2）まで落ちるため、0.20（隅 90.1）を採用。0.10 は効果がほぼ消える。

## 白飛ばし・黒潰れ（変更前→後、全画素に対する割合）
基準: 純白 = 3 チャンネルとも ≥253。いずれか飽和 = 最大チャネル ≥254。黒潰れ = 輝度 ≤8/255。
- 純白画素: 全 18 条件で 0.000% → 0.000%（増加なし）。
- いずれか飽和: 最大でも 0.05%（縦 p=0.5: 0.002%→0.050%）。横はほぼ 0。
- 黒潰れ: 全 18 条件で 0.004% 以下（縦 p=0.75〜1.0 で 0.001〜0.002% → 0.003〜0.004%）。
- 平均輝度: 昼景は上昇（縦 p=0: 129→141、横 p=0: 113→129）、夕景は低下（縦 p=1.0: 121→116）。1%点/99%点: p=0 縦 38→44 / 203→210、p=1.0 縦 23→21 / 199→193。
- 塔まわり（画面中央 40%×50%）の輝度標準偏差（コントラスト）: 縦 p=0 40.3→40.4、p=0.5 44.6→44.9、p=1.0 38.0→37.5。横 p=0 42.4→42.5、p=1.0 42.7→42.3 — 落ちていない。

## 負荷
