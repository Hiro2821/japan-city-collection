# 第1部：都市モジュール化 — 検証

方法: リファクタ前（HEAD=fad1fe0）の全進行度 p=0/0.10/0.25/0.47/0.50/0.53/0.75/0.94/1.0 を縦（390×844, T1）・横（960×540, T2）で撮影 → 移行後に同条件で撮影して画素比較。

- 画素差分: **18 枚すべて 0 px**（最大チャネル差 0）。`?city=sapporo` 指定（p=0.5, 1.0 縦）も 0、未知の `?city=nowhere` → 札幌にフォールバックして 0。モジュール版（`?bundle=0&three=local`）の p=0.5 横も 0。
- ドローコール・三角形: 18 地点すべて前後同一（例 縦 p=0: 185 / 2,076,511）。
- バンドル: 前回 0.834 MB（gzip 0.223）→ 0.841 MB（gzip 0.227）。+約 7 KB（契約検証・レジストリ・キャプション生成コード分）。
- 読み込み（tools/test-loading.mjs）: A 既定=bundle 4 ファイル 0.85 MB（gzip 0.23）。B/C/D = モジュール版 46 ファイル 2.30 MB（gzip 0.50）。前回 41 ファイル → +5（都市モジュールのファイル分割）。フォールバック 4 ケースとも ready。
- キャプション: DOM を都市モジュールの定義から生成するように変更。tools/test-captions.mjs の縦で窓ごとの表示（SAPPORO 札幌 / テレビ塔 / 大通公園 / 手稲山）と窓の重なりなしを確認。
