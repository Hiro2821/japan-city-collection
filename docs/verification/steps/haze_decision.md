# 霞（空気遠近法）— 強さの決定と比較（スクロール版のみ）

## 方式
`src/scroll/haze.js`（新規）。構築後、fog を使うマテリアルの `onBeforeCompile` に「fog_fragment の後ろ」で距離霞を差し込む。共有ファイル（src/scenes・src/lib）は無変更。
- 霞色 = 見ている方向の、その時刻の空の地平線色。空シェーダと同じ式 `mix(uHorizon, uHorizonWarm, pow(dot(視線,太陽),1.6))` をフラグメントごとに評価（空の uniform を共有）→ 昼の青→夕方のピンクに自動追従。
- 距離 start→end を smoothstep、上限 strength で霞色へ混合し、同時に彩度を落とす。
- 山並み（mountains）は上限を ×0.5 に抑え、最終構図のシルエットを残す。
- 対象外: 空（霞なし）、雪と光点（独自シェーダ）、車の光点。
- URL: `?haze=0` 無効（導入前と画素同一）／`?haze=1` 既定／倍率（例 1.5）。`?hazeStart= ?hazeEnd= ?hazeMax= ?hazeDesat= ?hazeMtn=` で個別調整。`?debug=1` に霞の設定を表示。

## 採用値
開始 700 m / 到達 7,000 m / 上限 0.60 / 彩度低下 0.55 / 山 ×0.5（= 候補「中」、倍率 1.0）。
候補: 弱 ×0.6、中 ×1.0、強 ×1.5（上限 0.36 / 0.60 / 0.90、山は各 ×0.5）。画像: `haze_cand_*.jpg`（左から 変更前｜弱｜中｜強）。

## 決定理由
- 遠景の繰り返し感: 弱は p=0.5 の遠景でまだ窓の繰り返しが見える。中・強は遠方の市街が空色に溶け、繰り返しが明確に減る。
- 近景: 3 段階とも p=0.5 縦の手前側は変化なし（開始 700 m より近いため）。
- 手稲山: 強は p=1.0 で右側の山体がかなり淡くなる。中は両端の山とも稜線が読める。
- 以上から、効果と「山が消えない」の両立で中を採用。強は ?haze=1.5 で試せる。

## 初回の調整（記録）
最初の試作（開始 900 / 到達 11,000 / 上限 0.62 / 山の抑制なし）は、p=1.0 で手稲山の右側山体が空に溶けかけたため、山の上限を半分にし、市街が溶ける距離を 7,000 m に縮めた。

## 負荷
ドローコール・三角形は 18 地点すべて前後で完全に同一（例 p=0.5 縦 70 / 976,154、p=1.0 横 250 / 1,850,595）。`?haze=0` は霞導入前ビルドと全 18 枚で画素差分 0。追加はフラグメントシェーダの数十命令（距離・方向の正規化・混合）のみ。
