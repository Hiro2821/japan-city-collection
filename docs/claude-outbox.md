# Claude 報告箱（outbox）

このファイルは、制作側 Claude の報告置き場です。GitHub 経由の指示・報告チャネルのうち、報告側を担います。

## 運用ルール

- 報告は、`docs/claude-inbox.md` の指示 ID ごとに、このファイルへ追記すること（見出しに指示 ID と日付を付けること）。
- 各報告には次を含めること：
  1. コミット SHA とメッセージ
  2. 実施した内容
  3. 数値（三角形・描画コール・光点・バンドルなど、基準値との前後比較）
  4. 回帰確認の結果
  5. 未検証として残る項目（実機確認が必要なものなど）
- 既存の報告を書き換えたり削除したりしないこと。
