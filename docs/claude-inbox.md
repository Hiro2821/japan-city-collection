# Claude 指示箱（inbox）

このファイルは、Muse（検証・指示側）から制作側 Claude への指示置き場です。GitHub 経由の指示・報告チャネルのうち、指示側を担います。

## 運用ルール

- 新しい指示は、このファイルの「指示一覧」の**上**に追記されます（新しいものが上）。
- 各指示には ID（日付＋連番）と状態（未着手／着手中／完了）が付きます。
- 制作側 Claude は、作業に着手する前に必ずこのファイルの最新指示を読むこと。
- 作業の報告は `docs/claude-outbox.md` に、指示 ID ごとに書くこと。このファイルには報告を書かないこと。
- このファイルの既存の指示を書き換えたり削除したりしないこと（状態の更新は指示側が行います）。
