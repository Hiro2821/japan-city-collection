# 大阪 地理・レイアウト（配置の決定）

目的：仕様書（`docs/cities/osaka-spec.md`）のルートを、本作の圧縮配置として数値で決める。
**確認の範囲と限界**：このセッションは地図アプリ・地理院タイルへ直接アクセスできない。位置関係・順序・ランドマークの高さ（梅田スカイビル 173 m、通天閣 108 m、あべのハルカス 300 m）は一般に知られた値を使い、通りの位置・幅・距離は記憶に基づく概略（★）。測量・DEM ではない。数値は `src/scroll/cities/osaka/layout.js` に集約し、後から直せる形にする。

## 1. 実地理の概略（記憶ベース★）
- 大阪駅・梅田は北の拠点。梅田スカイビルは駅の北西 約 400 m★、高さ 173 m（2 棟＋頂部の空中庭園）。
- 中之島は駅の南 約 1 km★。堂島川（北）と土佐堀川（南）に挟まれた中洲（東西 約 3 km★・幅 約 200 m★）。御堂筋が橋で渡る。
- 御堂筋は梅田から難波まで 約 3.3 km★ の南北の大通り（幅 約 44 m★、イチョウ並木）。イルミネーションは区間ごとに色が変わる。
- 道頓堀は心斎橋〜難波の東西の運河。御堂筋とは道頓堀橋で交わる。看板の固有ロゴは再現しない（D-4）。
- 新世界・通天閣は難波の南東 約 1 km★（通天閣 108 m）。あべのハルカスは天王寺 約 2 km★ 南、300 m。

## 5. 最終数値（2026-11-23 測定、tools/shoot-scroll.mjs・決定的描画）

| 項目 | 大阪 | 東京（比較） |
|---|---|---|
| 三角形（9 視点 × 縦横の最大） | 729,177（縦 p0.47）／範囲 718,954–729,177 | 544,000–581,000 |
| 描画コール（最大） | 165（縦 p0.10）／範囲 136–165 | 173 |

- 三角形は東京より約 25% 多い（遠景 12,000 棟・街路樹・高架など密度由来）。上限 180 万には十分な余裕があり、描画コールは東京以下。iPhone 実機の fps・発熱・メモリは未検証（オーナー確認待ち）。
- 回帰：札幌 6/6・仙台 5/6 が画素一致（仙台縦 p0 は最大 1/255 の丸め差のみ）。東京は 3D 描画が画素一致で、p1.0 の差分はフィナーレ案内文が「締め」から「Next — OSAKA」に変わった DOM 表示のみ（意図した変更）。大阪 ?tiles=0 の画素差分は 0。
- コレクション回帰（tools/test-collection.mjs を 4 都市へ拡張）：縦横とも全項目 OK（カード 4 枚、札幌→仙台→東京→大阪→締め→選択画面のフィナーレ連鎖を含む）。この VM では描画が重く、フィナーレのクリックだけ Playwright のタイムアウトを 180 秒へ延長した（検証内容は不変）。

### 実装中に見つけて直した不具合（記録）
- 横断通りの店舗パネルが御堂筋などの車道上に浮いて正面を向いていた → 交差する通りの帯域には置かないようにした。
- 環状線の列車帯は、上面の頂点も |z|=0.5 で側面扱いになり屋根まで窓明かりで光った（東京は真上から見ないため未発現）→ 法線で上面を判定し窓を側面だけに限定。あわせてインスタンス形状へ normal 属性のコピー漏れを修正し、近距離フェードとゲイン配線（1.4→0.8）を適正化した。
- 開幕の空が夕焼けに見えた → 太陽方位を南南東へ移し（北西向きの開幕画角に残照が入らない）、パレット移行を早めた。
