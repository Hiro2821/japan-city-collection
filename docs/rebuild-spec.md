- ステップごとに必ずコミット＆push する（環境消失対策）。

## 1. 進行度と時刻
- `t = min(1, p / 0.94) × 7.0 秒`（末尾約 6% は最終構図を保持）。
- 同じ p は同じ構図を再現する。逆スクロールでカメラも逆行する。
- 進行度 p = `clamp(-track.top / (track.height - stage.height), 0, 1)`。

## 2. カメラ
### 縦画面
- 塔の軸（geo 上 (-90, 0)）を画面中央に保ち、塔を周回する専用経路。
- **FOV 拡大だけの対処は禁止。** 位置・高さ・後退距離・注視点で調整する。
- 切替はアスペクト比（幅/高さ）で行う: ≤ 0.88 = 縦、≥ 1.12 = 横、中間は混合して跳ばない
  （位置・注視点・FOV を線形補間。重みは smoothstep(0.88, 1.12)）。
- 回転・リサイズで p が飛ばない。旧版には 0.5 → 0.81 に飛ぶバグがあり修正済みだった。再発させない
  （直前の安定した p を保持し、リサイズ後にその p へスクロール位置を戻す）。

### 横画面
- 動画版と同一を基本とする。
- **p = 0.40〜0.60 の区間のみ最初から調整する。** p = 0.47 / 0.50 / 0.53 でアンテナ先端が上端に触れず、余白を持って収まること
  （旧版の欠陥を再現しない）。FOV 拡大のみの対処は不可。
- それ以外の区間と縦画面経路は、この調整で変えない。

## 5. `?debug=1` パネル
通常表示では非表示。`?debug=1` のときのみ画面端に小さく表示し、タップでコピーできる。
- FPS（直近の平均と最大フレーム間隔）
- 品質ティアと変更履歴
- 実描画解像度（canvas 実ピクセル）、DPR
- p と t
- GL 呼び出し数・三角形数（`renderer.info`）
- WebGL レンダラー（GPU）文字列

## 6. 読み込み
- esbuild でバンドルし、**4 ファイル・約 0.89 MB（gzip 約 0.24 MB）** を目標とする。
- フォールバック: `?bundle=0` でモジュール版 / バンドル読み込み失敗時の自動切替 / CDN 不通時はローカル `vendor/three` に切替。
- `npm run build:scroll` で `dist/scroll.bundle.js` を生成する（src 変更後は必ず再生成）。
